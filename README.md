# HW3: Завантаження даних та основи SQL. DQL-команди

**Назва датасету:** UCI Adult (Census Income)

**Офіційне джерело:** [https://archive.ics.uci.edu/dataset/2/adult](https://archive.ics.uci.edu/dataset/2/adult)[cite: 10]

**Спосіб формування вибірки:** 
Дані отримано автоматизованим шляхом безпосередньо із сервера UCI за допомогою Python-бібліотеки `ucimlrepo`. За допомогою функції `fetch_ucirepo(id=2)` було завантажено оригінальний набір. Ознаки (features) та цільову змінну (targets) було об'єднано в єдиний Pandas DataFrame (`pd.concat`), після чого повний масив даних збережено у локальний файл `hw3_dataset.csv` для подальшого масового завантаження в PostgreSQL. Попередня фільтрація чи видалення записів на рівні Python не застосовувались.

**Кількість рядків:** 48 842

## Інструкція із запуску
1. Відкрийте файл зошита (`.ipynb`) у середовищі Google Colab.
2. У верхньому меню оберіть **Runtime (Середовище виконання)** -> **Restart & Run All (Перезапустити та виконати все)**.
3. Код автоматично розгорне локальний сервер PostgreSQL, стягне набір даних з офіційного джерела, виконає імпорт через `COPY FROM STDIN`, створить типізовану таблицю та послідовно виконає всі аналітичні SQL-запити.
